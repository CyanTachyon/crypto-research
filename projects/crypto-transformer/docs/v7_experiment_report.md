# V7 实验报告：Walk-Forward + 原始收益 + 3 种子集成

## 实验概览

| 项目 | 内容 |
|------|------|
| 实验名称 | V7 — Walk-Forward + 原始收益率 + 3 种子集成 |
| 实验日期 | 2026-06-02 |
| 实验目标 | 验证 walk-forward 框架 + 原始收益率目标能否超越 V4 |
| 核心改动 | 基于 V6 walk-forward 框架，恢复原始收益率目标，每窗口 3 种子集成，训练窗口增大到 720 天 |
| 结果摘要 | 整体 IC=-0.060, dir_acc=46.5%, 回测 -85.8%。在下跌市场中，原始收益率目标反而不如市场中性目标 |

## 摘要

V6 证明了 walk-forward 框架有效但市场中性目标过于保守。V7 假设：如果保留 walk-forward 框架但恢复 V4 的原始收益率目标，同时增加训练窗口（540→720 天）和每窗口 3 种子集成，应该能超越 V4 和 V6。

实验结果表明这个假设是错误的。V7 的 13 个窗口中仅 6 个 IC 为正（V6 为 9 个），整体 IC 为 -0.060（V6 为 +0.016），回测收益为 -85.8%（V6 为 +1.34%）。根本原因：测试期（2025.06-2026.06）市场下跌 45%，原始收益率目标让模型学到了强烈的做多偏差（81% long），在下跌市场中持续亏损。

---

## 1. V6 到 V7 改动

| 改动 | V6 | V7 |
|------|-----|-----|
| 预测目标 | 市场中性残差收益 | 原始 3 天收益率 |
| 每窗口种子数 | 1 | 3 |
| 训练窗口 | 540 天 | 720 天 |
| 集成方式 | 单模型 | 3 种子预测均值 |

其他参数保持一致：V4 的 25 维特征, dropout=0.35, weight_decay=0.10, 30 天步长。

## 3. 失败分析

### 3.1 为什么 V7 不如 V6

V7 用原始收益率目标导致模型在下跌市场中产生做多偏差（81% long），而 V6 的市场中性目标自动消除了方向偏差。在测试期市场跌 45% 的环境下：

- **V7**: 81% long → 在下跌中做多 → 亏损
- **V6**: 市场中性 → 不受市场方向影响 → 稳健

### 3.2 为什么 V7 不如 V4

V4 使用固定划分，虽然存在隐含的前视偏差，但在实践中效果更好。V4 的训练集包含了完整的牛市和熊市周期，模型学到的模式在测试期仍然部分有效。V7 的 walk-forward 训练窗口较短（720 天 vs V4 的全部历史），模型可能没有见过足够多的市场 regime。

### 3.3 Val IC 与 Test IC 的脱节

Window 8 的 val IC 高达 0.250（3 个种子都 >0.2），但 test IC 为 -0.065。这表明即使在 walk-forward 框架下，验证集 IC 仍可能是误导性的，因为验证集和测试集之间的市场 microstructure 可能快速变化。

## 5. 结论

1. **V4 仍是最佳版本**：固定划分 + 原始收益率 + 3 种子集成 = +14.0%
2. **Walk-forward + 原始收益率 = 更差**：V7 (-85.8%) 远不如 V4 (+14.0%)
3. **Walk-forward + 市场中性 = 稳健但不优**：V6 (+1.3%) 比所有其他 walk-forward 方案好
4. **预测目标的选择比训练框架更重要**：同样的 walk-forward 框架，市场中性 (V6) >> 原始收益 (V7)

### 迭代总结

经过 V1-V7 七个版本的迭代，核心发现是：

- **特征工程的天花板**：纯 OHLCV 衍生特征的信息含量有限，最强特征 |r|=0.125
- **外部数据不是银弹**：简单拼接外部数据会加剧过拟合（V5）
- **Walk-forward 更严格但结果可能更差**：更严格的评估 ≠ 更好的策略
- **V4 的成功部分归功于运气**：固定划分恰好让训练集和测试集的市场 regime 部分重叠

**最终排名**：V4 (+14.0%) > V6 (+1.3%) > V5 (-48.2%) > V7 (-85.8%)
