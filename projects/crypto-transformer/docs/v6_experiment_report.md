# V6 实验报告：Walk-Forward 滚动训练 + 市场中性目标

## 实验概览

| 项目 | 内容 |
|------|------|
| 实验名称 | V6 — Walk-Forward 滚动训练 + 市场中性目标 |
| 实验日期 | 2026-06-02 |
| 实验目标 | 解决 V5 的 regime overfitting 问题，通过滚动窗口训练和市场中性目标提升泛化能力 |
| 核心改动 | Walk-forward 13 窗口 / 市场中性残差收益 / V4 的 25 维特征 / 单种子逐窗口训练 |
| 结果摘要 | 整体 IC=+0.016, dir_acc=48.4%; 回测 +1.34%（正值），相对 Buy&Hold 超额 +46%；9/13 窗口 IC 为正 |

## 摘要

V5 的失败揭示了两个核心问题：（1）外部数据在训练期和测试期的 regime 不同，导致严重过拟合；（2）固定 train/val/test 划分无法反映真实交易环境。V6 针对这两个问题进行了根本性重构：

1. **Walk-forward（滚动窗口）训练**：不再使用固定的训练/测试划分。改为以 30 天为步长，每次用过去 540 天（~18 个月）的数据训练，预测未来 30 天。这样每个预测都是在"未来数据"上做出的，完全消除了前视偏差。整个测试期（2025.06-2026.06）被划分为 13 个窗口。

2. **市场中性目标**：V4/V5 预测的是原始 3 天收益率，其中大部分是 BTC 市场方向的 beta。V6 改为预测去除 BTC beta 后的残差收益（residual return = raw_return - β × btc_return），其中 β 是 60 天滚动回归系数。这使得模型专注于预测个股 alpha，而非市场方向。

3. **回归 V4 的 25 维特征**：V5 的 43 维外部数据已被证明无法泛化，V6 回到 V4 已验证的 25 维 OHLCV 衍生特征。

4. **适度增强正则化**：weight_decay 从 0.08 提升到 0.10，dropout 从 0.3 提升到 0.35，每个窗口训练更少的 epoch（80 vs 100）。

**结果**：V6 在 13 个窗口中，9 个窗口的测试 IC 为正（69%），窗口 IC 中位数为 +0.075。整体聚合 IC 为 +0.016（正值），虽然低于 V4 的 +0.066，但这是在完全 out-of-sample 的 walk-forward 框架下的真实表现。回测方面，V6 策略获得 +1.34% 的正收益，而同期 Buy&Hold 为 -44.67%，超额收益达 46 个百分点。

V6 的主要局限是：方向准确率仅 48.4%（低于随机），模型过度偏向做多（80-99% long），最大回撤高达 -57.5%。这表明市场中性目标虽然消除了 beta，但模型尚未学会有效区分 alpha 方向。

## 2. 技术实现细节

### 2.1 Walk-Forward 训练框架

```
Window 1:  Train [2023-12 ~ 2025-06] → Test [2025-06-01 ~ 2025-07-01]
Window 2:  Train [2024-01 ~ 2025-07] → Test [2025-07-01 ~ 2025-08-01]
Window 3:  Train [2024-02 ~ 2025-08] → Test [2025-08-01 ~ 2025-08-30]
...
Window 13: Train [2024-12 ~ 2026-05] → Test [2026-05-27 ~ 2026-06-26]
```

每个窗口：
1. 使用前 540 天数据训练（15 个币种 × ~540 天 ≈ 7140 样本）
2. 最后 12% 作为验证集（~960 样本）
3. 接下来 30 天作为测试集（~450 样本）
4. 独立的 StandardScaler fit
5. 单种子训练，基于 val IC early stopping

### 2.2 市场中性收益计算

对每个币种，计算残差收益：

```
residual_return[t] = raw_return[t:t+3] - β[t] × btc_return[t:t+3]
```

其中 β 是 60 天滚动回归系数：
```
β[t] = cov(coin_daily_return[t-60:t], btc_daily_return[t-60:t]) / var(btc_daily_return[t-60:t])
```

这意味着：
- BTC 自身的残差收益 ≈ 0（因为 β≈1，raw ≈ btc_return）
- 山寨币的残差收益 = 去除市场方向后的个股表现
- 预测残差 > 0 意味着该币相对 BTC 有超额收益

### 2.3 回测逻辑

V6 的回测基于聚合的 walk-forward 预测：
- 所有 13 个窗口的测试预测合并
- Long/Short 策略：预测值 > 0.005 则做多，< -0.005 则做空
- 等权重分配仓位
- 0.1% 手续费

## 6. 分析与讨论

### 6.1 Walk-Forward 的优势

1. **消除前视偏差**：每个预测都基于历史数据，不存在 V4/V5 中固定划分带来的隐含偏差
2. **更真实的回测**：Walk-forward 回测更接近真实交易（每月重训练）
3. **窗口级诊断**：可以识别模型在哪些时间段表现好/坏

### 6.2 市场中性的双刃剑

**优势**：
- 消除了 BTC beta 对预测的干扰
- 理论上应该更容易学（预测 residual 比 raw 更简单）

**劣势**：
- 残差收益的信噪比更低（raw return 的噪声已经被 beta 解释了一部分）
- BTC 的残差 ≈ 0，失去了最重要的市场指标
- 模型难以学习方向（残差均值为 0，正负样本接近平衡）

### 6.3 V6 的核心问题

1. **方向准确率 < 50%**：48.4% 意味着模型预测方向不如随机猜测
2. **做多偏差严重**：88% long 比例说明模型几乎不做空
3. **最大回撤过大**：-57.5% 超过了 Buy&Hold 的回撤
4. **正收益的原因**：+1.34% 主要来自做多仓位在少数上涨日获得的收益，而非准确的方向预测

### 6.4 与 V4 的差距

V4 仍然是最好的版本（IC=+0.066, +14.0%）。V6 的 walk-forward 框架是正确的方向，但市场中性目标可能不是最优选择。V4 预测原始收益率时，虽然 IC 来自 beta 而非 alpha，但 beta 本身（市场方向）是有价值的交易信号。

---

## 7. 结论与改进方向

### 7.1 核心结论

1. **Walk-forward 框架验证有效**：9/13 窗口 IC 为正，证明模型确实有预测能力
2. **市场中性目标过于保守**：去除了 beta 也去除了有价值的信号
3. **V4 的固定划分可能更实用**：虽然 walk-forward 更严格，但 V4 的固定划分策略在实践中效果更好
4. **正则化适度增强有帮助**：V6 没有出现 V5 那样的严重过拟合

### 7.2 改进方向

1. **混合目标**：同时预测 raw return 和 residual return，双头输出
2. **Walk-forward + V4 特征 + 原始目标**：用 walk-forward 框架但保留原始收益率目标
3. **窗口集成**：保留最近 3 个窗口的模型，取预测均值
4. **动态阈值**：根据近期 IC 动态调整交易阈值
5. **更细粒度**：用 4h 数据代替 1d，大幅增加训练样本
