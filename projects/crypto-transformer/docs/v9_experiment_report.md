# V9：V4 信号交易层优化 + Meta/Bandit/RL 实验报告

## 1. 实验目标

V9 不再尝试重新预测价格，而是把 V4 的弱预测信号当作 alpha 输入，系统测试多种交易层优化方法：固定阈值、Top-K、动态分位数、波动率目标、BTC regime filter、回撤 overlay、walk-forward 规则选择、meta-labeling、contextual bandit，以及直接 policy-gradient 仓位分配。

## 2. 数据与验证方式

- V4 checkpoint：只加载 `data/checkpoints/v4_seed_*.pt`，不重新训练 V4。
- 评估区间：`2025-11-28 to 2026-05-31`。
- 样本：2761 条预测，185 个交易日。
- 手续费：单边 `fee_rate=0.001`，按每日实际暴露收取。
- 训练方式：meta/bandit/policy 都采用 expanding walk-forward，只用过去窗口训练，未来 30 天交易。
- 排名分数：`Sharpe + Return - DrawdownPenalty - TradePenalty`，避免只按收益率选过拟合策略。

V4 信号在本评估窗口内的预测质量：

- 3日 IC：+0.0795
- 1日 IC：+0.0648
- 3日方向准确率：52.84%
- 1日方向准确率：52.81%

## 4. 最优策略判断（带方法学保留）

按风险调整分数，本次 V9 的全体事后排名第一策略是 **VolTarget-Quantile(q=0.20)**：收益 +53.40%，Sharpe 2.00，最大回撤 -14.49%。

但这里必须强调：它是“本次回测表格里的候选冠军”，还不能称为“已验证最优交易方法”。原因是我们同时比较了多组阈值、Top-K、分位数、波动率加权、regime filter、meta-labeling、bandit 和 policy-gradient；在同一个评估窗口里事后选第一，天然存在多重试验/数据挖掘偏差。

如果只看真正的学习类策略，表现最好的是 **Bandit-V4MaskedQ**：收益 +31.02%，Sharpe 1.76，最大回撤 -14.68%。它没有超过 `VolTarget-Quantile(q=0.20)`，也略低于固定 V4 阈值 `LS(th=0.005)` 的 +33.17%。所以本实验内可以说：复杂 RL/学习层没有证明优于简单交易层优化；但不能说 RL 方法本身被否定。

参考 V4 固定阈值 `LS(th=0.005)` 在同一评估窗口下：收益 +33.17%，Sharpe 1.74，最大回撤 -11.46%。
关键基线 `AlwaysShort(daily_fee)`：收益 +6.96%，Sharpe 0.52，最大回撤 -31.02%。如果它排名很高，说明市场 regime 本身贡献很大，不能把收益完全归功于模型。

## 7. 结论

V9 的核心判断不是“RL 能不能预测市场”，而是“在 V4 弱信号之上，哪种交易层能最稳健地把信号转化为收益”。本轮结果显示：最有效的不是复杂 RL，而是更简单的 **V4 信号 + 波动率归一化 + 横截面分位数选币**。这说明 V4 确实存在一点弱 alpha，但把它转成收益主要依赖仓位、风控和市场 regime 适配，而不是更复杂的预测模型。

不过，当前结论仍然是研究性结论，不是可实盘结论。主要限制包括：

1. **事后选优偏差**：`VolTarget-Quantile(q=0.20)` 是在同一评估窗口内横向比较后选出的第一名，需要额外 final holdout 或更严格 walk-forward 才能确认。
2. **交易时点风险**：部分状态特征使用当日 close 计算；若假设收盘后才得到信号，实际下单应整体后移一天或改成 next-open/next-close 执行。
3. **成本模型简化**：当前按每日 gross exposure 收费，而不是真实按 turnover、滑点、bid/ask、资金费和 short 成本收费。
4. **样本较短**：最终评估窗口只有 185 个交易日，Sharpe 2.0 需要 bootstrap、分月稳定性和不同手续费敏感性验证。

因此，最准确的结论是：**V9 找到了一个比原 V4 固定阈值更强的候选交易层 `VolTarget-Quantile(q=0.20)`，但它还需要严格 walk-forward/holdout/真实成本复核；复杂 RL 在本轮实现中没有超过简单规则。**
