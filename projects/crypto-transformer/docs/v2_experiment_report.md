# V2 实验报告：多尺度特征 + 双任务 Transformer

## 摘要

在 V1 基线实验的基础上，V2 进行了多项改进：引入多时间尺度特征（4h/12h/24h/48h 回报率、多窗口波动率）、跨资产特征（预测 ETH 时引入 BTC 指标）、时间编码（小时/星期周期特征）、4 小时预测窗口（替代 1 小时）、Focal Loss 解决类别不平衡、以及回归+分类双任务学习头。模型在 ETH/USDT 上产生了 **40 笔实际交易，胜率 57.5%**，策略收益 -0.60%，远好于 Buy & Hold 的 -34.48%。BTC/USDT 策略亏损 -11.73%，同样好于 Buy & Hold 的 -20.97%。

**结论：V2 的改进方向部分有效。Focal Loss 成功让模型产生了方向性预测（不再全预测 flat），回测产生了实际交易。但分类准确率（~25%）仍然低于随机基线，回归预测与真实收益率相关性接近零。策略虽然跑赢了 Buy & Hold，但主要受益于在下跌行情中仓位较轻，而非主动择时能力。**

## 1. V1 → V2 改动清单

### 1.1 特征改进
| 改动 | V1 | V2 |
|------|----|----|
| 特征维度 | 17 | **25** |
| 多时间尺度回报率 | 无 | **4h/12h/24h/48h log return** |
| 多窗口波动率 | 无 | **4h/12h/24h 滚动标准差** |
| 价格范围特征 | 无 | **4h/24h high-low range** |
| 时间编码 | 无 | **hour sin/cos + day-of-week sin/cos** |
| 跨资产特征 | 无 | **BTC return + BTC/ETH 波动率比** |
| 价格/成交量 | ATR 归一化 | **ATR 归一化 close + 滚动归一化 volume** |

### 1.2 任务改进
| 改动 | V1 | V2 |
|------|----|----|
| 预测窗口 | 1h | **4h** |
| 阈值 | ±0.5% | **±1.0%** |
| 学习目标 | 3分类 | **3分类 + 回归（双任务头）** |
| 损失函数 | CrossEntropy + class weights | **Focal Loss (γ=2.0) + Huber Loss** |

### 1.3 架构改进
| 改动 | V1 | V2 |
|------|----|----|
| Context 长度 | 48 步 | **128 步** |
| 位置编码 | 正弦 | **可学习** |
| 输入投影 | Linear | **Linear + GELU + LayerNorm** |
| 参数量 | 804K | **879K** |
| LR 调度 | ReduceLROnPlateau | **CosineAnnealingWarmRestarts** |

V2 Transformer 的分类准确率大幅下降（0.71 → 0.28），但原因在于 Focal Loss 使模型改变了预测策略：

**ETH/USDT:**

## 3. 分析

### 3.1 为什么准确率反而下降了？

V1 准确率 70%+ 是虚假的——模型通过全预测 flat 获得"高准确率"。V2 的 Focal Loss 强制模型关注少数类（up/down），导致模型积极预测方向。准确率从 70% 降到 28%，但这是更真实的评估——模型终于在学习方向性模式，只是学得不好。

### 3.2 为什么 ETH 回测表现比 BTC 好得多？

- **ETH**: 40 trades, 57.5% win rate, -0.60% return — 接近盈亏平衡
- **BTC**: 39 trades, 43.6% win rate, -11.73% return — 明显亏损

ETH 的 cross-asset feature（BTC return）可能提供了有效信息。BTC 本身是市值最大的加密货币，没有"更大"的资产可以作为参考，跨资产特征价值更低。

### 3.3 双任务头是否有用？

回归头的预测（corr ≈ 0）几乎无用，但它在训练中提供了额外的梯度信号，可能间接帮助了分类头。没有消融实验无法确认。

### 3.4 严重过拟合

V2 的 train_loss 持续下降（0.02 → 0.003），但 val_loss 从 0.008 涨到 0.07+，过拟合非常严重。128 步 context 和 25 维特征增加了模型容量，但数据中的信号不足以支撑。

## 5. V3 改进建议

### 5.1 解决过拟合（最高优先级）
- **更强的正则化**: dropout 提高到 0.3-0.4，增加 label smoothing
- **更小的模型**: d_model=64, 2 层，减少参数量
- **数据增强**: 对时序特征添加微小噪声（jittering）、时间窗口随机裁剪
- **更短的 context**: 从 128 降到 64 或 32

### 5.2 纯回归任务
- 放弃分类头，只做回归
- 预测收益率本身，用 IC（Information Coefficient）和 Rank IC 评估
- 交易信号来自回归预测的符号和幅度

### 5.3 换一个更可行的目标
- **波动率预测**: 已实现波动率比收益率更容易预测
- **相对排序**: 不预测绝对方向，而是预测"未来 4h ETH 是否会跑赢 BTC"
- **极端行情检测**: 二分类——是否会出现 >3% 的大幅波动

### 5.4 更好的训练策略
- **Warmup + Cosine Decay**: 替代 CosineAnnealingWarmRestarts（导致周期性震荡）
- **Gradient Accumulation**: 等效 batch_size=256，更稳定的梯度
- **SWA (Stochastic Weight Averaging)**: 平均多个 checkpoint 的权重
