# Base 链网格量化交易机器人

基于 Base L2 的加密货币网格交易策略机器人，支持模拟和实盘两种运行模式。自动在价格区间内铺设买卖单，利用市场震荡获利。

## 策略概述

网格交易（Grid Trading）是一种经典的量化策略。核心思路很简单：选定一个价格区间，按等比间距布置一组买单和卖单。价格每下跌穿过一条网格线就买入，回升穿过上方的线就卖出，低买高卖，反复吃价差。

这种策略最适合震荡行情。价格来回波动越频繁，网格成交次数越多，累计收益越高。反过来，单边趋势行情是网格策略的天敌：持续上涨时你早早卖光了筹码，持续下跌时你一路接飞刀。

## 网格触发逻辑

### 价格线生成

以当前价格为 `centerPrice`，按多层间距模式分布 6 条价格线：

- **内层**（0.5%）：1 买 1 卖，捕捉微小震荡
- **中层**（1.2%）：1 买 1 卖，捕捉中等波动
- **外层**（3.5%）：1 买 1 卖，捕捉较大波动

底层 3 条线标记为买入，顶层 3 条线标记为卖出。当 `tiers` 未配置时，回退到几何等比间距模式（向后兼容）。

### 触发判定

每轮询价拿到 `currentPrice`，与上一轮的 `previousPrice` 比较，检测是否穿越了某条网格线：

- **买入触发**：`previousPrice > level.price` 且 `level.price >= currentPrice`（价格从上方穿过买入线）
- **卖出触发**：`previousPrice < level.price` 且 `level.price <= currentPrice`（价格从下方穿过卖出线）

### 成交后的网格变化

买单成交后，紧邻其上方的那条线会被重新激活为卖单。卖单成交后，紧邻其下方的那条线会被重新激活为买单。这样网格可以持续运作，不会因为成交而耗尽。

### 网格重建（Recenter）

当价格偏离中心价超过 5%（网格范围的约 1.67 倍），以当前价格为中心重新生成全部网格线，之前的成交记录和持仓状态会保留。

## 收益预估

以 CBBTC/USDC 为例：

```
理论每次网格利润: ~$0.04~$0.26 (多层间距不同)
扣除费用后实际利润: ~$0.03~$0.25
```

网格策略的盈利严重依赖波动频率。价格必须在网格范围内来回震荡才能持续获利。如果出现单边行情（持续上涨或下跌），网格策略会持续亏损。

## 风险管理

系统内置 6 条风控规则，在实盘模式下每笔交易前逐一检查：

| 规则 | 参数 | 触发动作 |
|------|------|---------|
| 止损 | 价格低于中心价 8% | 立即停止（STOP_LOSS） |
| 最大回撤 | 净值回撤超过 25% | 紧急退出（EMERGENCY_EXIT） |
| 熔断器 | 单轮触发超过 2 个网格层级 | 暂停 60 秒（PAUSE） |
| Gas 上限 | 单笔 Gas 超过 $0.10 | 跳过该笔（SKIP） |
| 日消费上限 | 当日累计花费超过 $10 | 跳过该笔（SKIP） |
| ETH 储备 | ETH 余额低于 0.005 ETH | 紧急退出（EMERGENCY_EXIT） |

### 紧急停止机制

除风控规则外，还支持三种紧急停止方式：

1. **文件触发**：在项目根目录创建名为 `stop` 的文件
2. **环境变量**：设置 `EMERGENCY_STOP=true`
3. **信号**：发送 SIGINT 或 SIGTERM

紧急停止后，机器人暂停所有网格检测和交易执行，但进程不会退出，等待人工处理。

### 串行交易执行

同一时刻只处理一笔交易，避免并发导致的状态冲突。

## 技术架构

### 技术栈

| 组件 | 技术 |
|------|------|
| 语言 | TypeScript (ESM, NodeNext) |
| Web3 库 | viem |
| DEX | Aerodrome（实盘主路径）+ Uniswap V3（报价/备用） |
| 精度 | BigInt（所有金额计算，零浮点） |
| 持久化 | JSON 文件（每交易对独立状态文件） |
| 日志 | pino（控制台 pretty + JSON 文件双输出） |
| 通知 | Telegram Bot（可选） |
| 配置校验 | zod |
| 测试 | vitest |

### 价格获取

采用两级容灾架构：

1. **主数据源**：链上报价（Uniswap V3 QuoterV2 合约），通过 `quoteExactInputSingle` 查询 1 USDC 能兑换多少代币，反算出精确价格
2. **备用数据源**：DefiLlama API，当链上报价失败时自动切换

价格统一转换为 USDC 6 位精度（微美元）的 BigInt 表示。

### 精度处理

所有内部计算使用 BigInt，避免浮点数精度丢失。不同代币的精度转换通过 `toUsdcValue` / `fromUsdcValue` 函数处理：

- USDC: 6 位
- WETH: 18 位
- CBBTC: 8 位（注意，不是标准的 18 位）

## 使用方法

### 安装依赖

```bash
npm install
```

### 模拟模式

不需要私钥，不需要钱包，直接从链上读取真实价格，用模拟资金运行：

```bash
npm run start:sim
# 或直接
node --import tsx src/index.ts
```

模拟模式会：
- 从链上获取实时价格
- 用 $50 模拟资金（全部投入 CBBTC/USDC）
- 扣除模拟的 DEX 手续费、Gas、滑点
- 输出每笔交易的详细费用明细和 P&L

### 实盘模式

需要配置环境变量（通过 `.env` 文件或 PM2 ecosystem）：

```bash
npm run start:live
# 或
node --import tsx src/index.ts --mode=live
```

实盘模式启动前会执行预检：
- 检查 ETH 余额是否 >= 0.005 ETH（Gas 储备）
- 检查 USDC 余额是否 > 0
- 检查 USDC 和 WETH 是否已授权给 Aerodrome Router

如果预检失败，机器人会拒绝启动。

### 查看日志

日志文件存储在 `data/` 目录下，按时间戳命名：

```bash
ls data/bot-*.log
```

控制台输出使用 pino-pretty 格式化，日志文件为 JSON 格式，方便后续分析。
