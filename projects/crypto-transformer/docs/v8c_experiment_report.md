# V8-C 实验报告：加密货币统计套利（配对交易）

## 1. 实验动机与假设

### 1.1 背景回顾

在 V1-V7 系列实验中，我们尝试用 Transformer 模型预测加密货币的日收益方向。V4 是最佳版本，信息系数（IC）达到 +0.066，策略年化 Sharpe 为 0.63，总收益 +14.04%。然而，根因分析指出：日收益预测的信息论极限是真正的瓶颈，而非模型架构。

### 1.2 为什么转向统计套利？

统计套利（Pairs Trading）是一种与方向预测根本不同的策略范式：

- **无需预测价格方向**：不关心 BTC 是涨是跌，而是利用两个相关资产之间价差的均值回复特性
- **市场中性**：理论上对冲了系统性风险（beta），收益来源于相对价值回归
- **文艺复兴科技的策略核心**：Medallion 基金年化约 66% 收益，核心方法之一就是统计套利
- **适用于震荡市**：在下跌行情中，配对交易可以天然对冲市场风险

### 1.3 实验假设

**H1**：加密货币之间存在协整关系（co-integration），价差具有均值回复特性

**H2**：基于 z-score 的信号生成可以在价差偏离时建仓，回归时获利

**H3**：统计套利策略在风险调整后收益上可以超越 V4 的方向预测策略和买入持有基准

## 2. 方法论

### 2.1 数据与配对

- **资产池**：15 种加密货币（BTC, ETH, SOL, BNB, XRP, ADA, AVAX, LINK, DOT, UNI, OP, AAVE, LTC, ATOM, NEAR）
- **配对组合**：C(15,2) = 105 个可能的配对
- **数据频率**：日线 OHLCV
- **数据范围**：2022-06-01 至 2026-06-02（1,463 个交易日）
- **训练/测试分割**：训练截止 2025-06-01（仅用于初始筛选），Walk-forward 回测覆盖全时段

### 2.2 协整检验

对每一对资产（A, B）执行以下检验：

**Engle-Granger 检验**：
1. 对 log(A) 做 OLS 回归 log(B)：log(A) = α + β·log(B) + ε
2. 对残差 ε 进行 ADF 检验（Augmented Dickey-Fuller）
3. 若 ADF p < 0.05，则认为 A 和 B 协整

**Johansen 检验**：
1. 构建二元 VAR 模型
2. 检验协整矩阵的秩（trace 统计量）
3. 在 95% 置信水平下判断是否存在协整关系

**对冲比率（Hedge Ratio）**：OLS 回归系数 β

**半衰期（Half-life）**：对价差拟合 AR(1) 模型，计算 half-life = -ln(2)/ln(φ)，其中 φ 为 AR(1) 系数

### 2.3 信号生成

对于选中的配对（A, B），对冲比率 β：

```
spread = log(A) - β × log(B)
z_score = (spread - rolling_mean(spread, 20)) / rolling_std(spread, 20)
```

**交易信号**：
- z_score > +2.0 → 做空价差（做空 A，做多 B×β）
- z_score < -2.0 → 做多价差（做多 A，做空 B×β）
- z_score 回归至 ±0.5 内 → 平仓

### 2.4 Walk-Forward 回测

为避免前视偏差，采用 walk-forward 验证：

- **形成期**：360 天（使用扩展窗口，随时间增长）
- **交易期**：60 天
- **滚动步长**：30 天
- **动态配对选择**：每个窗口重新测试全部 105 个配对，选择当前协整的配对
- **最大同时持仓**：10 个配对

### 2.5 仓位管理

- 等权重分配给所有活跃配对
- 每个配对的仓位 = 1/N_active_pairs
- 交易成本：0.1%/笔（与 V4 一致）
- 不使用杠杆（1x）

## 3. 协整分析结果

### 3.1 全样本协整检验

| 指标 | 值 |
|------|-----|
| 测试配对数 | 105 |
| EG p < 0.05（协整） | 2 |
| EG p < 0.10 | 2 |
| 通过 Johansen 95% | 105 |
| 同时通过两者 | 2 |

**关键发现**：在 4 年的全样本上，仅 2 对加密货币通过 5% 显著性水平的协整检验。

### 3.2 最佳协整配对

| 配对 | EG p-value | 对冲比率 β | 半衰期（天） | 样本内 Sharpe | Johansen 95% |
|------|-----------|-----------|-------------|-------------|-------------|
| AVAX/UNI | 0.0260 | 1.1408 | 42.7 | -0.40 | ✓ |
| DOT/OP | 0.0293 | 0.5166 | 62.9 | +0.67 | ✗ |

### 3.3 半衰期分布

仅考虑 p < 0.30 的配对的半衰期：
- 最小值：42.7 天
- 中位数：128.9 天
- 平均值：125.3 天

**解读**：半衰期普遍较长（>40天），说明加密货币价差的均值回复速度较慢，可能不适合高频配对交易。

在 walk-forward 回测中，协整关系在不同时间窗口中有显著差异：

## 5. 与 V4 对比分析

### 5.1 策略差异

| 维度 | V4（方向预测） | V8-C（统计套利） |
|------|-------------|---------------|
| 核心思路 | 预测哪个币会涨跌 | 利用价差均值回复 |
| 市场暴露 | 多空但带方向偏 | 理论上市场中性 |
| 信号来源 | Transformer 模型预测 | 统计检验（ADF, OLS） |
| 数据需求 | 特征工程（25 维） | 仅需价格序列 |
| 模型复杂度 | 深度学习模型 | 简单统计方法 |

### 5.2 为什么 V8-C 不如 V4？

1. **加密货币协整关系弱**：全样本仅 2 对通过 5% 协整检验，远低于传统股票市场
2. **半衰期过长**：多数配对半衰期 >40 天，价差回归速度慢，单笔交易利润薄
3. **协整不稳定**：不同窗口中协整关系频繁断裂，导致策略失效
4. **熊市环境**：2025-2026 测试期整体下跌，协整关系更容易因极端行情而崩溃
5. **交易成本侵蚀**：频繁调仓（4,480 次），0.1% 的交易成本累积显著
6. **AAVE 等小币对影响大**：盈利配对多涉及 AAVE，可能是过拟合而非真实的协整关系

### 5.3 V8-C 的相对优势

1. **跑赢买入持有**：在极端下跌行情中减少了约 7% 的损失
2. **无需训练模型**：方法简单，不需要 GPU
3. **可解释性强**：每笔交易都有明确的统计依据

## 6. 风险分析

### 6.1 协整关系断裂风险

这是统计套利最大的风险。当两个资产的长期关系突然改变时（如监管事件、技术升级），价差可能不再回归，导致持续亏损。

本次实验中，XRP/ATOM 配对亏损 -23.57%，很可能就是协整关系断裂的案例。

### 6.2 极端行情风险

2025-2026 年加密市场经历了显著下跌，所有 15 种币均大幅下挫。在这种系统性风险下：
- 价差可能被同向运动主导，失去对冲效果
- 流动性下降导致滑点增大
- 协整关系的统计基础被破坏

### 6.3 过拟合风险

16/37 个配对盈利可能部分源于：
- 在有限窗口中碰巧协整
- 对历史参数（阈值、窗口期）的隐式优化
- 小币种（AAVE, ATOM）价格波动带来的随机盈利

### 6.4 交易成本敏感度

以 4,480 次交易 × 0.1% 计算，总交易成本约为 4.48% × 平均仓位，对总收益有显著侵蚀。

## 7. 结论与展望

### 7.1 核心结论

1. **假设 H1 部分成立**：加密货币之间存在协整关系，但非常微弱且不稳定。全样本仅 2 对通过 5% 显著性检验，远低于传统市场

2. **假设 H2 部分成立**：z-score 信号生成在某些配对上有效（16/37 盈利），但整体胜率偏低（43.6%）

3. **假设 H3 不成立**：V8-C 的风险调整后收益（Sharpe -0.24）显著劣于 V4（Sharpe +0.63），统计套利在加密货币日频数据上不如方向预测有效

### 7.2 方法论洞察

- **加密市场不适合传统配对交易**：与传统股票市场不同，加密货币的高波动率和低协整性使得统计套利的利润空间有限
- **协整是时变特性**：动态配对选择比固定配对更合理，但协整关系在加密市场中仍然太不稳定
- **半衰期是关键瓶颈**：40+ 天的半衰期意味着资金利用效率极低

### 7.3 可能的改进方向

1. **更高频率数据**：使用小时或分钟级数据，可能发现更短半衰期的协整关系
2. **动态阈值优化**：根据波动率调整 z-score 阈值
3. **Kalman Filter 对冲**：替代 OLS 的固定对冲比率，使用时变对冲比率
4. **跨交易所套利**：在不同交易所间寻找价格差异，而非资产间价差
5. **机器学习增强**：用模型预测价差方向，而非纯统计方法
6. **组合优化**：考虑配对间相关性进行组合层面优化

### 7.4 V8-C 在实验系列中的定位

V8-C 验证了一个重要假设：在加密货币日频数据上，统计套利不如方向预测有效。这与传统市场形成鲜明对比（在传统市场中，统计套利通常优于简单的方向预测）。根本原因在于加密市场的特殊性：高波动、低协整、趋势性强。
